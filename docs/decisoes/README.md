## Como registrar uma decisão nova

1. Copie [`0000-modelo.md`](0000-modelo.md) para `NNNN-titulo-curto.md` (próximo número, minúsculas, sem acento).
2. Preencha. Seja curto: o que importa é o **porquê** e o que foi **descartado**.
3. Acrescente a linha na tabela acima.
4. Para **mudar** uma decisão, não edite a antiga: escreva uma nova e marque a antiga como "substituída por NNNN".
